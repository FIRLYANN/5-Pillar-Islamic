# MUSLIMTECH — 5 Pilar, 1 Era Digital

Website edukasi statis tentang hubungan lima Rukun Islam, Al-Qur'an, dan pemanfaatan teknologi secara bertanggung jawab.

## Cara menjalankan

**Cara paling mudah:** buka `index.html` langsung di browser.

**Lewat VS Code:**
1. Ekstrak folder project.
2. Buka folder `5-pilar-era-digital` di Visual Studio Code.
3. (Opsional) Pasang ekstensi Live Server.
4. Klik kanan `index.html` → **Open with Live Server**.

Project ini menggunakan HTML, CSS, dan JavaScript biasa. Tidak perlu `npm install`, backend, database, API key, atau akun Bolt.

## Struktur file

- `index.html` — struktur dan konten website.
- `styles.css` — desain, layout, dan responsive styling.
- `script.js` — navigasi mobile, kuis, kalkulator edukasi, dan pencarian glosarium.

## Fitur

- Navigasi antarbagian dan menu mobile.
- Materi landasan Al-Qur'an dan lima Rukun Islam.
- Etika digital dan prinsip tabayyun.
- Kuis interaktif 5 pertanyaan dengan skor dan pembahasan.
- Kalkulator edukasi zakat maal (estimasi sederhana).
- Glosarium dengan pencarian istilah.
- Layout responsif untuk desktop dan ponsel.

## Catatan materi

Teks ayat dan terjemahan sebaiknya selalu dicocokkan kembali dengan sumber resmi Qur'an Kementerian Agama RI. Tautan rujukan ayat tersedia pada halaman website. Kalkulator zakat hanya alat simulasi pendidikan, bukan fatwa atau penetapan kewajiban zakat.

## Mengembangkan project

Kamu dapat mengubah konten pada `index.html`, desain pada `styles.css`, dan perilaku interaktif pada `script.js`. Karena tidak menggunakan framework atau backend, project ini mudah dipindah, diedit, dan dikembangkan di VS Code.
